# As-Salah für Android

Download-Seite und Update-Feed für die App **As-Salah** (Gebetszeiten & Qibla-Kompass).

**Seite:** https://shoaib87-ger.github.io/As-Salah-Andorid/

Dieses Repository enthält nur die Auslieferung:

| Datei | Zweck |
|---|---|
| `index.html` | Die Download-Seite (DE / EN / دری) |
| `latest.json` | Version, Datum, Größe und „Was ist neu" — wird von der Seite UND von der App gelesen |
| `downloads/AsSalah.apk` | Die App. Der Dateiname bleibt bei jedem Update gleich, damit der Link stabil ist |

Kein Quellcode, keine Schlüssel. Die App wird aus einem separaten, privaten
Repository gebaut und signiert.
